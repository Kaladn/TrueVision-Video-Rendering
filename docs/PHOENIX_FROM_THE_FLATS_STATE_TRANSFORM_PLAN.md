## State Glossary

### System Roles

AnchorWorks:

```text
Meaning, language, anchors, counts, ClearSpeak, memory, operator-facing interpretation.
```

SecureCore:

```text
Policy, gates, safety, runtime verification, receipts, provenance, retention authority.
```

TrueVision:

```text
Visual state logging, visual state recognition, visual transform operators, replay/proof surfaces.
```

TrueAudio:

```text
Audio state logging, stem meters, timing, pulse, spectrum, vocal/section pressure.
```

### Core Terms

State:

```text
Measured condition at a time and region.
```

Transform:

```text
A measured change from one state to another.
```

Operator:

```text
Reusable transform rule that can be applied to compatible state.
```

State Event:

```text
Timed detection of a visual/audio change.
```

Region:

```text
The area affected by a state event or transform.
```

Mask:

```text
A bounded selection of source pixels/cells that a transform is allowed to affect.
```

Plate:

```text
An input visual surface. It is not automatically evidence. Its state may be logged.
```

Stem Driver:

```text
An audio stem or derived audio lane used to modulate a transform.
```

Evidence Metrics:

```text
Measured support for a state event, such as luma delta, edge density, bloom pressure, motion energy, or texture shimmer.
```

Reusable Transform Candidate:

```text
A detected state change that may become a reusable operator after review.
```

Generated Proof:

```text
Output media made to show the transform. It is synthetic and not source truth.
```

Source Truth:

```text
Approved state logs, manifests, receipts, cell state, timing metadata, and reviewed operator packets.
```
