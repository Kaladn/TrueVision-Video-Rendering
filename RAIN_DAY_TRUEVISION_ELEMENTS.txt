TRUEVISION GENERATION LAB - RAIN DAY ELEMENTS

Purpose
-------
Build a local audio/video state-media lab for recording, replaying,
regenerating, generating, and learning from visual/audio state.

This is not evidence generation.
This is not desktop automation.
This is not prompt-to-magic-video.

Core law:

Forward TrueVision witnesses.
Reverse TrueVision replays, regenerates, or demonstrates state.
Generated media is synthetic state media, not evidence.
Raw frames are not implied unless explicitly saved.

Playback Clarity Notes
----------------------
The current replay is honest to stored cell RGB mean state.

If it looks almost perfect but slightly smeared or phase-shifted, likely causes:

video content does not exactly fill the desktop
browser/player chrome is included
letterbox or pillarbox bands are included
content rectangle is not snapped to the TrueVision grid
Windows/display scaling shifts the visible video area
sub-cell detail is lost inside each 4x4 cell

Next fix:

detect active video rectangle
crop to exact content area
snap crop to 16:9
force crop width/height divisible by grid
record crop origin
record cell size
record phase/alignment metadata

TrueFrameGen
------------
Purpose:

Fill missing frames from existing TrueVision cell-state captures.

Pipeline:

recorded frames
-> TrueVision cell state
-> 6-1-6 temporal map
-> missing-frame cause/effect estimate
-> generated in-between state
-> rendered frame
-> verification pass

Hard law:

TrueVision records.
6-1-6 explains temporal causality.
TrueFrameGen fills only the missing state between known states.

Current modules:

trueframegen/temporal_616.py
trueframegen/causal_cell_map.py
trueframegen/state_interpolator.py
trueframegen/frame_gap_filler.py
trueframegen/render_missing_frame.py
trueframegen/verify_replay_continuity.py

CLI:

python scripts\trueframegen_fill.py --run-dir D:\path\to\truevision_capture --radius 6
